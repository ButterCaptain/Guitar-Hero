Solid lines are written to the 640×480 pixel buffer (Bresenham, 1 px). Guide lines are dashed overlays and never become pixels. Row rules fill whole pixel rows inside a piece of the trapezoid.

Time t (0–480, +1 at 60 Hz)
t = 0
Scales the whole motion uniformly: t advances by this many ticks per frame, so the cycle takes 480 ÷ speed frames. The per-piece delay is counted in t ticks.
Makes the front start further away so it covers more distance in the same time. The tick at which each front reaches the base does not change; the front just enters the trapezoid later and moves this many times faster.
Rules with +t treat V1/V2 as offsets from a moving reference line. t = 0 puts it at y = 0 and t = 480 at y = 480 (with height above base: base to height 480).
Constant depth speed: the reference line starts at the trapezoid’s top edge at t = 0 and reaches y = 480 at t = 480 (reveal mode: the last piece’s front reaches the base at t = 480); the slider is ignored. Screen profile: 0 = constant 1 px per tick. At 1 the line moves 2× faster at the bottom of the screen than at the top.
