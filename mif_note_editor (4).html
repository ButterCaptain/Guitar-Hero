MIF note editor

Five lanes, 16-bit notes (hold flag + 15-bit frame), one .mif file with a lane header.

None loaded
Playhead: frame 0 (0.000 s)
/
Hover over a lane to place a note.

Click an empty spot to place a note with the selected tool. Clicking an existing note applies the selected tool to it (Tap or Hold changes its type, Erase removes it). Right-click always removes. A hold note extends to the next note in its lane; if it is the last note, a dashed default length is shown. The .mif starts with a 10-word header (note count and start address for each lane), followed by the notes of lane 1, then lane 2, and so on with no gaps or terminators. Click the ruler or waveform to move the playhead. Frames are 15 bits, so a chart can span at most 32767 frames (about 9:06 at 60 fps). Test run starts at the playhead; play with D, F, Space, J, K, or tick Auto-play to watch. Tempo, time signature and the beat grid only help with placing notes and are not written to the .mif. Drag the waveform or use the arrows to shift the audio; this never moves notes or the song start frame.

Keys: D F Space J K
