Hover over a lane or the effects row.

Notes: click an empty spot in a lane to place a note with the selected tool. Clicking an existing note applies the tool to it (Tap or Hold changes its type, Erase removes it). Right-click always removes. A hold extends to the next event in its lane.

Effects: click the purple Effects row to add an effect with the current Effect value (0 = flash). Click an effect to select it, then change the value box to edit it. Right-click (or the Erase tool) removes it. While the song plays, press E to drop an effect exactly where you hear something; the faint line it draws through the lanes shows which notes it lines up with. Test run plays the chart with the flashes, so you can check them against the music.

Files: notes.hex is the 10-word header (note count, then start address, of each lane) followed by every lane's notes; each word is bit 15 = hold, bits 14..0 = frame. effects.hex is word 0 = number of effects, then one 32-bit word per effect sorted by frame: bits 14..0 = frame, bits 31..15 = effect value. Both memories hold at most 2048 words. Frames are 15 bits, so a chart can span at most 32767 frames (about 9:10 at 59.5238 fps).

Click the ruler or waveform to move the playhead; drag the waveform or use the arrows to shift the audio. Tempo, time signature and the beat grid only help with placement and are not exported.
